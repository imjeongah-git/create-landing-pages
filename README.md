# 행사·사업 랜딩페이지 만들기

Codex에서 계획안·공고문·키비주얼·참고 사이트를 주고, 단계별 질문 카드와 시안을 보며 랜딩페이지를 만드는 스킬입니다.

자료 받기 → 구성 → 디자인·움직임 → 첫 화면 비교 → 전체 콘텐츠 → PC·모바일 검수 → 공개 순서로 진행합니다. 기존 페이지의 일정·사진·로고 교체와 행사 후 다시보기도 지원합니다.

## 설치

저장소 접근 권한이 있는 계정으로 이 저장소를 내려받은 뒤 `skills/event-program-landing` 폴더를 사용자 Codex 스킬 경로 `~/.codex/skills/` 아래에 복사합니다. 이미 같은 이름의 스킬이 있으면 변경 내용을 확인하고 갱신합니다. 새 Codex 채팅에서 스킬이 보이는지 확인합니다.

Codex의 skill-installer가 GitHub 경로 설치를 지원하는 환경에서는 이 저장소의 `skills/event-program-landing` 경로를 지정해 설치할 수도 있습니다. 비공개 저장소는 해당 계정의 접근 권한이 필요합니다.

## 시작

`$event-program-landing으로 행사 랜딩페이지 만들어줘. 계획안은 있고 키비주얼은 아직 없어.`

또는 `사업 모집 페이지 만들어줘`라고 요청합니다. 계획안·공고문, 로고, 참고 URL을 가진 것부터 같은 채팅에 전달합니다. 선택 카드가 지원되지 않는 환경에서는 채팅의 번호 선택으로 진행합니다.

사이트 제작·이미지 생성·게시 도구와 계정은 실행 환경에 있는 기능을 사용합니다. 설치만으로 호스팅 계정이나 공개 권한이 생기지는 않습니다.
