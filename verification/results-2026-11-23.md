# 2026-11-23 실사용 평가

설치된 스킬로 독립 실행자가 가상 행사 페이지를 제작하고 검토자가 사용자 역할로 답했다. 카드 도구 대신 스킬에 정의된 Markdown 카드 경로를 사용했다.

## 수행

- 기본 자료 확인부터 구성, 디자인 방향 3개, PC·모바일 첫 화면 2개, 전체 콘텐츠, 화면 검수, 미리보기 인계까지 진행했다.
- 키비주얼·연사·신청 링크가 없는 온라인 행사로 시작했다.
- 오렌지 1안을 선택하고 모바일에서 제목과 시간이 먼저 보이도록 반영했다.
- 신청 버튼을 비활성화하고, 눌리는 것처럼 보이지 않도록 회색으로 조정했다.
- 후속 요청으로 질문 시간을 Q&A로 변경하고 관련 설명과 생성 소스를 함께 수정했다.
- 별도 사업 모집 요청 두 턴에서 자료 재질문과 행사 전용 항목을 생략하고 문구·구성·추천 디자인 방향만 작성했다.

## 실제 브라우저 확인

Chrome headless에서 375×812, 1440×900, 1280×720 세 화면의 가로 넘침 없음, 2개 신청 버튼 모두 비활성, 프로그램 섹션 이동 성공, 페이지 오류 없음과 이미지 로딩 실패 없음을 검토자가 확인했다. 실행자의 추가 측정은 키보드 포커스·건너뛰기 링크·참여 안내 이동·움직임 줄이기와 비활성 버튼의 클릭 이벤트 차단을 확인했다.

## 발견과 수정

첫 시안 응답이 상대경로 이미지를 사용했다. 이후 응답과 저장소·설치본 지침을 절대경로 이미지와 실제 파일 존재 확인으로 수정했다.

## 미검증

Codex 앱의 실제 질문 카드 UI와 클릭, 실제 사람의 사용성, 실제 PDF 공고문 판독, 실제 모바일 하드웨어, 공개 호스팅·접근 권한, 외부 접수 완료, 새 채팅에서 재개는 미검증이다. 미리보기 유지로 종료했다. 이 기록은 공개 배포 전 과정의 통과를 의미하지 않는다.
