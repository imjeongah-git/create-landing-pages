# 후속 카드와 검수

## 새 계획안 반영

기존 확정 내용과 새 문서의 시간·명칭·순서·발표자를 비교표로 보여준다. 해당하는 행에 기존 값, 새 값, 출처, 영향받는 화면을 적는다. 명시적으로 요청한 변경은 실행하고 중요한 충돌은 확인한다. 프로그램표·연사·사례·번역·메뉴에 쓰인 같은 정보를 함께 반영한다. 과거 문서에서 사용자가 제외한 등록·휴식 행 등이 새 문서에 있으면 충돌로 표시한다.

## 사진·로고·명단 교체

사용자 제공 원본과 웹용 파일을 프로젝트 안에서 분리해 보관하고 출처를 기록한다. 원본을 삭제해도 운영 파일이 유지되는지 실제 참조를 확인한다. 공식 출처를 우선해 로고를 수집하고 동명 기업을 구분한다. 못 찾은 항목과 후보가 불확실한 항목을 목록으로 돌려준다.

로고의 색·문자·심볼을 보존하면서 배경 대비와 눈에 보이는 크기를 맞춘다. 사진은 배경 톤·얼굴 면적·크롭을 비교한다. 변환 도구는 환경 지침과 요청에 맞춰 선택한다. 사례 카드·애니메이션·번역 등 동일 자산의 모든 사용처를 확인한다. 컨소시엄 매칭과 공급기업·수요기업 순서는 해당 프로젝트의 확정 기준으로 적용한다. 로고 수집·중복 제거와 사업 참여 주체의 집계는 각각 확인한다.

## 한영 전환·상호작용

요청된 언어의 첫 두 화면을 먼저 보여주고, 선택 후 전체 문구·메뉴·버튼·접근성 이름에 적용한다. 행사명·기관·직함 등 고유명사는 확인 가능한 공식 표기를 사용한다.

대표 카드 하나로 데스크톱 hover·click과 터치 scroll·tap을 비교한다. 가로 PC와 세로·좁은 화면에서 내용이 열리는 방식이 의도대로 작동하는지 확인한다. 사용자가 선택한 방식이 같은 종류의 카드에 일관되게 적용되는지 시험한다. 클릭 고정·다시 닫기·스크롤 이동 후 상태도 확인한다.

## 홍보용 자산

파비콘, 검색·공유 제목·이미지, 밝은 배경·어두운 배경용 아이콘, 투명 PNG 중 요청한 것을 출력한다. 기존 승인 자산을 활용하고 출력 크기·배경·텍스트 포함 범위를 확인한다. 화면 캡처 보정 요청인지 실제 웹 원본 수정·출력 요청인지 맥락에서 판단하고 중요한 모호함만 확인한다. 사이트 수정·배포와 파일 추출 결과는 각각 기록한다.

## 신청 성과와 행사 후 전환

추적은 버튼 클릭 / 링크 경유 / 실제 접수 완료 중 현재 데이터로 가능한 지표를 표시한다. 실제 완료 신호가 없는 외부 폼에서 클릭을 접수 완료로 계산하지 않는다. 소급 집계 가능 범위와 시작 시점을 기록한다. 관리자·체크인 연결은 요청한 범위와 연결 가능한 시스템을 확인한 뒤 진행한다.

행사 후에는 접수 마감·다시보기·결과 아카이브 카드 중 요청한 것을 연다. 영상은 사례별 URL 대응표를 만들고 대표 영상 하나의 실제 임베드 재생을 확인한다. 권한·퍼가기·운영 환경을 확인하고 이용 가능한 URL부터 확대한다. 로컬 파일 시험 성공을 온라인 게시 완료로 기록하지 않는다.

## 화면과 게시 검수

기본 확인 화면은 좁은 모바일 375×812, 가로 PC 1440×900, 낮은 PC 1280×720이며 실제 타깃에 맞게 추가·조정한다.
- 첫 화면 이미지 비율·잘림, 긴 한글 제목, 가독성, 가로 넘침.
- 고정 메뉴·신청 버튼·하단 아이콘이 본문이나 다른 버튼을 가리는지.
- 프로그램표의 시간 순서·줄바꿈·긴 행, 콘텐츠를 끝까지 읽을 수 있는지.
- 사례 1개·홀수 개 등 실제 개수에서 배치와 로고 크기 균형.
- 사진 누락·교체와 로고 로딩, PC·터치·키보드 접근, 포커스와 읽을 수 있는 대비.
- 섹션 이동, 위아래 스크롤, 과도한 움직임과 reduced-motion 대응.
- 신청 버튼·지도·문의·외부 링크의 목적지, 선택한 언어 전환.
- 운영 URL과 공개 범위, 게시 버전, 네트워크·콘솔 오류.

검수 기록은 수행한 화면·행동·결과·미확인 사항을 담는다. 도구가 없어 확인 못한 사항은 완료로 표시하지 않는다.
