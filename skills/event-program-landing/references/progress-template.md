# 진행 기록 양식

프로젝트 루트 LANDING-PROGRESS.md에 다음 항목을 실제 값으로 기록한다. 초기에는 모르는 항목을 미정으로 두고 작업할 때 갱신한다.

- 페이지 목적과 방문자의 대표 행동
- 현재 카드와 다음에 필요한 결정
- 작업 폴더와 실제 수정 대상
- 받은 자료 목록과 버전·출처·확인일
- 자료에서 추출한 핵심 사실과 충돌
- 선택한 구성·시안·문구·상호작용·언어
- 미확정 항목과 나중에 받을 자료
- 원본·웹용 자산 위치와 재사용 위치
- 콘텐츠·개발 완료 상태
- 미리보기 주소와 검수한 화면·행동·결과
- 게시 대상·공개 범위와 사용자 승인 범위
- 마지막 게시 버전·시점 및 운영 URL 검증 결과
- 실패·미확인 사항과 다음 행동

기존 기록을 읽고 현 상태와 대조한 다음 갱신한다. 계정 비밀정보를 적지 않는다. 보고서 작성이나 시간 집계는 별도 요청이 있을 때 범위를 정한다.
