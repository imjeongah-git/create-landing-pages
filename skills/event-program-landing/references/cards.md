# 단계별 카드

아래 문구는 시작 예시다. 받은 자료에 맞춰 질문을 줄이고 실제 내용으로 채운다. 한 번에 현재 카드만 표시한다.

## 1/7 기본 자료

**이미 파악한 내용** 자료가 있으면 행사명·사업명, 대상, 일시·마감, 장소, 핵심 목적을 출처와 함께 요약한다.

**선택**
- 페이지 종류는 행사 안내·참가 신청 / 사업 소개·모집.
- 자료는 계획안·공고문 / 내용 붙여넣기 / 간단한 설명으로 시작.
- 키비주얼은 이미지 제공 / 로고로 시안 제안 / 나중에 제공.
- 참고는 URL·캡처 제공 / 예시 보고 선택 / 추천에 맡기기.

파일·URL은 같은 채팅에 보내도록 일반 메시지로 안내한다. 처음부터 네 질문을 모두 도구에 넣지 말고 이미 파악한 항목을 제거한 뒤 도구 제한에 맞게 묶는다.

**결과** 제작 요약에 확정·잠정 정보를 적고 자료 충돌과 중요한 누락만 확인한다. 자료가 없으면 이름·대상·핵심 행동을 간단히 받아 시작한다.

## 2/7 방문 목적과 페이지 구성

“방문자가 마지막에 무엇을 하면 좋을까요?” 자료에 따라 참석 신청 / 사업 신청 / 문의 / 정보 확인 중 관련 선택만 제시한다. 링크를 이미 받았다면 연결 목적을 요약한다.

행사 기본 구성은 첫 화면 → 행사 의미 → 프로그램 → 연사·사례 → 장소·문의다. 사업은 첫 화면 → 지원 대상 → 혜택·내용 → 일정·절차 → 신청 방법·문의다. 필요에 따라 섹션을 합치거나 뺀다.

**결과 예시**
| 순서 | 방문자가 알게 될 내용 | 버튼·연결 |
|---|---|---|
| 첫 화면 | 누구를 위한 어떤 행사인지 | 참석 신청 |
| 프로그램 | 참여할 이유와 시간 | 관심 세션으로 이동 |
| 장소·문의 | 도착 방법과 연락처 | 지도 열기 |

실제 내용을 넣은 구성표와 버튼 문구를 보여주고 추천 구성 사용 / 구성 수정으로 진행한다. 접수 시작·마감 상태가 있으면 버튼의 상태도 정한다.

## 3/7 디자인과 움직임

참고마다 “가져올 부분”을 적는다. 예를 들어 포스터의 색·오브제, 사이트 A의 화면 전환, 사이트 B의 프로그램표를 조합한다.

선택지는 “한 화면씩 넘기기 / 자연스럽게 내려 읽기 / 예시 보고 고르기”처럼 표현한다. 한 화면 방식도 내용이 길거나 화면이 낮을 때 읽을 수 있어야 한다.

키비주얼이 없으면 로고와 목적에 맞는 작은 시안을 기본 3개 제안한다. 더 많은 안을 원하면 요청 수에 맞춘다. 고른 안에서 색·글꼴·여백·이미지 사용 방식을 요약하고 다음 카드로 간다.

**결과** 디자인 방향 요약과 저해상도 이미지 또는 시각적 예시. 실물 비교 없이 전문 용어만으로 선택을 요구하지 않는다.

## 4/7 첫 화면 비교

같은 제목·슬로건·일시·이미지로 두 안을 만들고 PC·모바일을 함께 보여준다. 차이는 제목 위계, 여백, 오브제 비중, 버튼 배치처럼 판단 가능한 요소로 설명한다.

“1안 / 2안 / 두 안 섞기” 선택을 제공하고 직접 수정도 받는다. 첫 화면과 다음 섹션까지 작동하게 해 이미지 비율·잘림, 메뉴, 신청 버튼 가림, 스크롤 전환을 함께 확인한다.

**결과** 선택한 미리보기, 변경할 요소와 유지할 요소를 진행 기록에 저장한다.

## 5/7 전체 콘텐츠

선택한 구성에 맞춰 필요한 묶음만 연다.
- 행사 프로그램은 시간·순서·세션명·발표자·장소.
- 연사·패널은 이름·소속·직함·순서·사진.
- 사례·협력기관은 기업명·기관명·매칭·과제명·표기 순서·로고.
- 사업 모집은 지원 자격·내용·혜택·신청 기간·제출물·접수 방법.
- 공통은 신청 URL·지도·교통·주차·문의·주최 및 관련 링크.

파일과 표를 읽어 연결 관계를 추출한다. 누락 자료가 있는 구간은 공개예정 표기로 미리보기를 만들 수 있다. 허구의 인물·지원 조건·실적 수치를 넣지 않는다. 미확정 상태로 공개할 중요한 항목은 게시 카드에서 다시 보여준다.

**결과** 전체 페이지 초안과 미확정 항목. 디자인 선택을 전체 페이지에 일관되게 적용한다.

## 6/7 화면 검수

PC와 모바일의 비교 화면 및 작동하는 주소를 제공한다. 긴 내용·홀수 개 카드·사진 비율·버튼 가림 등 실제 문제를 먼저 고치고 사용자에게 주요 선택만 보여준다.

“현재 안 사용 / 표시한 부분 수정”으로 받는다. 캡처 또는 자유 설명으로도 수정 가능하다고 안내한다. 바꾼 부분은 전후 화면으로 확인하고 관련 페이지·언어를 함께 검수한다.

**결과** 검수한 크기·행동·수정 결과와 미확인 사항을 기록한다.

## 7/7 공개와 인계

처음 게시라면 “미리보기 유지 / 제한 공유 / 전체 공개” 중 환경이 지원하는 선택을 제공한다. 지원하지 않는 공유 방식은 가능하다고 제시하지 않는다. URL·대상·공개 범위·신청 목적지를 보여준다. 이미 게시 승인을 받은 수정은 그 범위에서 진행한다.

**결과** 실제 확인한 주소, 게시 버전·시점, 원본·웹용 자산 위치, 미확정 항목, 후속 수정 방법을 전달한다. “사진만 교체해줘”, “새 계획안 반영해줘”로 재개할 수 있다고 안내한다.
